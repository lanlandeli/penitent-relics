# Penitent Relics · 忏悔遗物

《以撒的结合：忏悔+》道具扩展模组，围绕遗物的力量与代价，带来新的战斗体验。

## 道具

| 图标 | 道具 | 效果 |
|---|---|---|
| ![Crude Salt](mod/resources/gfx/items/collectibles/crude_salt.png) | **粗盐 · Crude Salt** | 攻击有概率记录敌人的移动方向。敌人反向移动时化为盐雕，Boss 则受到额外伤害。 |
| ![Trinity](mod/resources/gfx/items/collectibles/trinity.png) | **三位一体 · Trinity** | 获得魂心、飞行与射速提升。攻击在圣父、圣子、圣灵之间轮转，组合印记触发审判。 |
| ![Forbidden Fruit](mod/resources/gfx/items/collectibles/forbidden_fruit.png) | **禁果 · Forbidden Fruit** | 每层起始房提供两件临时道具，可付费选择一件，并按品质降低本层伤害；放弃没有惩罚。 |

更多内容会随开发陆续加入。

## 使用

将 `mod/` 中的内容复制到游戏模组目录下的 `PenitentRelics/` 文件夹，
重启游戏并在 Mods 菜单启用。开发和测试部署见[工作流](docs/development/agent_workflow.md)。
